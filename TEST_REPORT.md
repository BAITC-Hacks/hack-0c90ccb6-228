# Проверка пакета Smart Contractor

Дата: 23.09.2026. Проверялся именно этот проект с новым интерфейсом и рабочим API.

## Выполнено

- Python 3.12.14: `python -B -m pytest -q -p no:cacheprovider` — **29 passed**, 4,75 секунды. `NODE_BINARY` указывал на установленный Node; тесты матрицы не пропускались.
- `node --check static/app.js`, `static/date-matrix.js` — успешно; `static/tailwind-config.js` ранее проверен и не менялся.
- `bash -n start.sh` — успешно.
- Живой запуск через Uvicorn: `/healthz` — 200, 66 профилей; интерфейс загружается вместе с новым `date-matrix.js`.
- `/.env`, `/.git/config`, `/requirements.txt` — 404; сервер не раздаёт корень проекта.
- Браузер: метаданные формы загружаются через `/api/meta`, подбор — через `/api/match`.
- Основной запрос возвращает 3 карточки; редкая категория — 2 и причину неполной выдачи; занятые залы — пустую выдачу с аудитом; отсутствие категории — отдельное состояние.
- Другая дата меняет выдачу; слепой режим скрывает имена и инициалы.
- Реальные счётчики воронки совпадают с результатом API. Синтетические профили и дополненные цены отмечены.
- Матрица появляется после поиска и содержит ровно семь кнопок. Выбранный день всегда четвёртый; начало и конец календаря проверены, дни вне диапазона отключены.
- Автоматическая сверка **1200 семидневных матриц** (12 наборов условий × 100 дней): каждый счётчик в диапазоне совпал с `eligible_count` серверного подборщика. Проверены бюджет, категория, город, формат, язык, длительность, пустая выдача и числа больше трёх.
- Проверены переходы месяцев и года, високосный февраль и три часовых пояса; невалидные даты отклоняются.
- Браузер: 23 сентября — 4 подходящих ведущих при 3 карточках; клик на 24 сентября меняет поле формы, выделение и состав результатов.
- Браузер: банкетные залы 6 декабря — «Нет мест»; переход на 7 декабря — 3 варианта и 3 карточки. Красные, жёлтые и зелёные числа соответствуют количеству. Нулевые даты остаются доступными для выбора.
- Клавиатура: Tab переводит фокус на соседний день, Enter запускает подбор; после перерисовки фокус сохраняется на выбранной дате.
- Переключение даты сохраняет город, категорию, бюджет, формат и слепой режим; в слепом режиме три карточки остаются «Кандидат #1–3».
- Экраны 320 и 390 px: горизонтального переполнения страницы нет, прокручивается ряд дат. На 390 px выбранная карточка находится точно в центре видимой части ряда. Расположение на 1280 px проверено визуально.
- При редактировании параметров матрица скрывается до нового поиска, чтобы не показывать счётчики от предыдущих условий.
- Архив проверяется на целостность, обязательные файлы, отсутствие секретов и временных папок; `.gitignore` проверяется через Git.

## Пределы проверки

- Проверки выполнены без реального OpenAI-ключа. Сетевой контракт SDK тестируется через MockTransport, а в браузере используется честно обозначенный резервный режим. Фактический ответ OpenAI нужно проверить после настройки собственного ключа.
- Docker Engine здесь не установлен: образ и Compose локально не запускались. В GitHub Actions добавлена сборка и проверка контейнера на порту 8080 — она выполнится после загрузки репозитория, если Actions включён.
- GitHub Actions, внешний деплой, домен и HTTPS в этой сессии не запускались.
- Pytest выдаёт одно предупреждение Starlette о будущем переходе тестового клиента с httpx на httpx2; все тесты проходят.
